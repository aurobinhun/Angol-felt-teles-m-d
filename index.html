Angol Feltételes Módok (Conditionals) Összefoglaló

Az angolban öt fő feltételes szerkezetet különböztetünk meg attól függően, hogy a feltétel mennyire reális, és milyen időre (jelen, jövő vagy múlt) vonatkozik. Fontos szabály: az "if" tagmondatban szinte soha nem használunk will-t vagy would-ot!

0. Zero Conditional (Általános igazságok, természeti törvények)

If + Present Simple, Present Simple / Imperative

Olyan dolgokra használjuk, amelyek mindig igazak, ha a feltétel teljesül (tudományos tények, szokások, automatizmusok, utasítások). Az if itt gyakran helyettesíthető a when szóval.

If you heat ice, it melts.

Ha felmelegíted a jeget, elolvad.

1. First Conditional (Reális jövőbeli feltétel)

If + Present Simple, will / can / may / might / should + V1

Valós, lehetséges jövőbeli helyzetekre és azok várható következményeire használjuk. A főmondatban will helyett állhat can, may, might, should vagy felszólító mód is.

If it rains tomorrow, we will stay at home.

Ha holnap esik az eső, otthon maradunk.

2. Second Conditional (Képzeletbeli, valószínűtlen jelen/jövő)

If + Past Simple, would / could / might + V1

Jelenlegi vagy jövőbeli irreális, képzeletbeli vagy nagyon valószínűtlen helyzetekre használjuk (magyarban: "-na/-ne/-ná/-né"). A "to be" ige alakja minden személyben lehet were (pl. If I were you...).

If I won the lottery, I would buy a big house.

Ha megnyerném a lottót, vennék egy nagy házat.

3. Third Conditional (Múltbeli, meg nem történt feltétel)

If + Past Perfect (had + V3), would / could / might + have + V3

A múltra vonatkozik, amin már nem tudunk változtatni (bánat, megkönnyebbülés, múltbeli mi lett volna ha). Magyarban: "volna" segédigével fejezzük ki.

If you had studied harder, you would have passed the exam.

Ha keményebben tanultál volna, átmentél volna a vizsgán.

Mixed Conditionals (Vegyes feltételes módok)

3. + 2. típus vagy 2. + 3. típus

Két különböző idősíkot kapcsol össze:
• Múltbeli feltétel → Jelenbeli következmény: If + Past Perfect, would + V1
• Jelenbeli általános állapot → Múltbeli következmény: If + Past Simple, would have + V3

If I had taken that job, I would be rich now.

Ha elvállaltam volna azt az állást (múlt), most gazdag lennék (jelen).

If she weren't afraid of flying, she would have travelled with us.

Ha nem félne a repüléstől (általános jelen), velünk utazott volna (múlt).
